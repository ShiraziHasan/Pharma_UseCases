MODEL DISCLOSURE — Shortcut multicomponent FUG method (Fenske / Underwood / Gilliland-Molokanov). VLE from Antoine vapor pressures + a simplified multicomponent (ternary-extended, symmetric) Margules activity-coefficient model, pairwise-calibrated to literature-typical behavior for CH₃OH–CHCl₃–IPA–H₂O (not regressed NRTL/UNIQUAC). Light key: CH₃OH. Heavy key: H₂O. CHCl₃ and IPA are treated as distributed (non-key) components via Hengstebeck–Geddes. Saturated-liquid feed (q=1) and constant molal overflow assumed. Steam duty is calibrated to a field baseline of 750 kg/h at design reflux (R=3.0) — this is a screening-grade tool; validate against a rigorous NRTL/UNIQUAC simulation (e.g. DWSIM) before using outputs to set real DCS setpoints.
